# Auditory-Environmental-Multi-Class-Classification

## Overview
This project contains the notebook file for a google Colab based CNN network that classifies audio into five key categories which are animals, natural soundscapes, human non-speech, interior(domestic) sounds, and exterior(urban) sounds. The data used for training, validating, and testing this CNN is the ESC-50 dataset uploaded to Hugging Face by ashraq.

## How to Run
1. Open the notebook in Google Colab or any Jupyter Notebook Enviroment
2. Install dependencies: (full list of necessary dependencies is included within the first notebook cell)
3. For new, full training iterations, run all cells. To only evaluate the pre-trained models, import the datasets, run cells that set up the CNN model and datasets, and then run the final notebook cell.
